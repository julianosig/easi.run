## Runtime inventory

Everything in the runtime images: the admin, the controller, and the images each session runs. The easi.run code and its client are AGPL-3.0-only; everything they use keeps its own license, listed below (the encoders, the agent's driver, the client's packages, each image's packages, and the Rust crates each binary links). A Debian copyright file names every license of every file in a package, so each package with a GPL term is listed with what the image actually ships.

### Encoders

- `openh264-sys2`: OpenH264 2.7.0, BSD-2-Clause, compiled from source into the display binary only in builds with the h264 feature, which the published images leave off (Cisco's H.264 patent coverage applies only to its own prebuilt binary; see below).

- `opus`: libopus 1.5.2, BSD-3-Clause (with the patent licenses its authors grant for Opus, RFC 6716); compiled from its checksummed release source archive (scripts/opus.sh) into a static library linked into the display binary, so no package in the SBOM carries it.

## Codec patents

Copyright licenses do not settle patent rights. AV1 is covered by the Alliance for Open Media's royalty-free patent license, and the published display image encodes video only in AV1. H.264 is patent-encumbered: a build with the h264 feature compiles OpenH264 from source, and Cisco's patent coverage applies only to Cisco's prebuilt binary, not to a source build, so such a build needs its own patent position.
